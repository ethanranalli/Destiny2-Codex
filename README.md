# Destiny 2 Codex Helper

A folder-based Destiny 2 assistant for builds, gear, guides, farming, progression, PvP, lore, and support. Reviewed September 6, 2026.

Open a Codex task in this folder. [AGENTS.md](AGENTS.md) guides behavior; topic files provide the relevant knowledge on demand. These instructions apply to tasks using this workspace, not to unrelated projects or all chats globally. Codex discovers project instructions from the working directory; this folder has no Git root, so start tasks at its root. See [official AGENTS.md guidance](https://learn.chatgpt.com/docs/agent-configuration/agents-md).

Good requests:
- "Build my Warlock for duo Equilibrium, prioritize reliable damage, and include every mod and artifact pick."
- "Keep or shard this roll for Trials and PvE?"
- "I am on this quest step; give me the next three actions."
- "Use my vault export to make the strongest solo Hunter setup I can actually equip."
- "Explain this raid encounter, including roles, callouts, wipe causes, and recovery."
- "What is worth farming this reset for my next upgrade?"

The helper has live source routing and dated notes. It does not update itself in the background. A fresh link check is not a fresh measurement. It checks relevant live information when a question needs it; older public snapshots stay historical.

Personal gear, DLC ownership, and completed quests remain unknown until supplied. Existing community spreadsheets and catalyst images are reference material. No universal "best build" or in-game performance has been validated by this maintenance pass.
