Use the current Director/activity card. [Bungie's activity guide](https://help.bungie.net/hc/en-us/articles/46668136913172--10-Activities) and [baseline notes](../00-start-here/source-notes.md) explain current access; an older guide's launch node can be wrong.

Solo, Fireteam, Arena, Pinnacle, Crucible, and Gambit Ops are routing categories. Do not infer matchmaking, player cap, Power, modifiers, equipment lock, or reward eligibility from the hub name alone.

For a farm, compare eligible rewards per actual hour, including wipes, loading and resets. A higher difficulty is not automatically a better farm.
