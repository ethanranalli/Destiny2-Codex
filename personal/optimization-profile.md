# Optimization Profile

Last updated: 2026-06-16

## Core Profile

| Topic | Preference |
|---|---|
| Main classes | Hunter and Warlock |
| Lower priority class | Titan, unless specifically requested |
| Activity mix | PvP and PvE, broad mix of everything |
| Fireteam size | solo or duo with one friend |
| Platform | Epic Games on PC |
| Input | mouse and keyboard |
| Spoilers | allowed |

## Optimization Bias

Use optimal meta picks based on current numbers.

The helper should think in terms of:

- speedrun-style strategies
- high-end DPS rotations
- survivability optimization
- meta weapon and perk performance
- actual tested values over popularity
- current sheet and source dates
- solo/duo practicality

## Build Guidance

When recommending builds:

- prioritize Hunter and Warlock
- include both simple loop and advanced rotation when useful
- make it easy to read and apply
- include all necessary data
- include DIM-style summary notes when useful
- optimize around personal exports once they exist
- avoid dream builds by default unless asked

## Weapon Guidance

When discussing weapons:

- separate PvE and PvP verdicts
- use labels: `Keep`, `Shard`, `Test`, `God Roll`, `Niche`, `Replace`, `Archive`
- use current date and best judgment when sources conflict
- prefer newer tested data over old popularity data
- include Champion coverage when relevant

## Source Guidance

- Browse live sources automatically for current or meta-sensitive questions.
- Use personal exports first once available.
- Use live public Google Sheets for DPS, perk values, hidden mechanics, and endgame viability.
- Use official Bungie sources for patch state and rules.
- Do not cite every source unless asked, but name sources when browsing or live sheets materially shape the answer.
