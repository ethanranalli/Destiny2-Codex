# Quests and Campaign Steps

Reviewed: 2026-09-06.

Give the next action first. Use the player's exact quest title/objective and current step; distinguish account-wide unlocks from character-specific progress.

## Triage

| Quest type | Check |
|---|---|
| Campaign | Ownership, launch path, exact mission, difficulty, prior quest hand-in |
| Exotic weapon/catalyst | Present source, prerequisite, item ownership, completion and claim steps |
| Subclass/aspect/fragment | Class, selected subclass, campaign/unlock/vendor prerequisites |
| Guardian Rank/title/triumph | Exact current objective, rank/character requirements, hidden or time-limited conditions |
| Archived pass/season | Present reward access, currency, ownership; reward archive is not proof an old mission is playable |
| Collectible/puzzle | Exact object, location/instance, quest dependency, character progress |
| Blocked objective | Inventory space, quest capacity, wrong difficulty/version, missing hand-in, known issue |

Use [guide protocol](../activities/guide-protocol.md) for an ordered walkthrough. Mention launch node, prerequisites, objective steps, success cue, reward claim, and next step.

Current Director names may differ from old guides. Check [baseline evidence](../00-start-here/source-notes.md) before sending the user to retired Legends or legacy ritual nodes.

Do not claim current loadout slots require an old Guardian Rank objective; the checked 9.7.0 baseline provides 20 on login. Other system unlocks still need their own objective check.

For account progress use personal data or the user's current wording. Unknown is not incomplete. Do not mark a quest finished merely because a recommended step was explained.
