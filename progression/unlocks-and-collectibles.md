# Unlocks, Triumphs, Titles, and Collectibles

Reviewed: 2026-09-06.

Use exact current objective text and personal progress. Cover subclasses, aspects/fragments, exotic class item access, catalysts, crafting patterns, Guardian Ranks, seals/titles/gilding, collections, destination collectibles, and raid/dungeon challenges.

## Completion plan

| Question | Required evidence |
|---|---|
| What remains? | Current checklist/export or user-reported objective |
| Where is it? | Exact location/map and instance/quest prerequisites |
| Can I complete it now? | Availability, ownership, rotation, time gate |
| Solo or team? | Actual objective's fireteam requirements |
| Does a checkpoint count? | Continuous-run/completion rules for that objective |
| What counts as completion? | Exact trigger, claim step, character/account scope |
| What if progress fails? | Known issue, wrong variant, missing prerequisite, claim/relaunch condition |

For collectibles use [Braytech](https://bray.tech/) and the [community map library](../00-start-here/community-guides.md). Account-specific checkboxes require current personal evidence; a public map does not show what the user has collected.

Rank a title/challenge plan by blockers, rotation-sensitive objectives, shared progress opportunities, and required practice. Do not assume every retired event's triumph remains earnable, or that historical gilding is available.

If asked to save a tracker, create a dated Markdown checklist with source, current state, next action, and dependencies. Do not mark steps done unless the user or fresh account data confirms them.
