## Pick a source by what it can prove

| Source | Use | Limit |
|---|---|---|
| [Bungie News](https://www.bungie.net/7/en/news) | Official changes and announcements | News list needs JavaScript; open the exact article |
| [Bungie Help](https://help.bungie.net/hc/en-us) | Access, account, error codes, support | Some articles retain legacy examples |
| [Server/update status](https://help.bungie.net/hc/en-us/articles/360049199271-Destiny-Server-and-Update-Status) | Outages, maintenance, version reference | Check displayed event date; not a complete changelog |
| [Known issues](https://help.bungie.net/hc/en-us/articles/39007140765204-Destiny-2-Known-Issues-and-Vital-Information) | Disabled/broken interactions and blockers | Reconcile later fixes and section date |
| [Official baseline and patches](source-notes.md) | Current-system evidence and historical references | One canonical baseline for this folder |
| [Ritual Reset Guide](https://help.bungie.net/hc/en-us/articles/360049199911-Destiny-2-Ritual-Reset-Guide) | Reset time and Tuesday cadence | Old activity/bounty lists can be superseded |
| [Bungie's resource directory](https://help.bungie.net/hc/en-us/articles/46900914493460--11-Bungie-and-Destiny-2-Resources) | Officially linked community tools | A listing is not an endorsement of every ranking |
| [API reference](https://bungie-net.github.io/), [API repository](https://github.com/bungie-net/api) | Item definitions, manifests, schema context | No custom integration or credentials needed for routine advice |

## Owl Sector access note

Checked: **2026-10-02**. [Owl Sector](https://owlsector.net/) rendered successfully in the text reader. Its homepage credits the Data Compendium, Clarity, Destiny 2: Endgame Analysis, and Boss DPS Spreadsheet. It provides Artifacts, Abilities & Subclasses, Weapons, Glossary, and Game Mechanics sections.

The homepage displayed data last refreshed **2026-10-02, 15:36:49** (timezone unspecified) and site version **v1.8.2**. This is the site's refresh timestamp, not proof that every underlying value was recently tested. Use it as a convenient lookup alongside the local Compendium-first workflow; preserve question marks and resolve conflicting annotations through the attributed original source. Ratings require activity context and damage values require original test conditions. This access check did not validate every entry.

Do not read every row for every request. Keep account exports local. Do not copy whole workbooks or publish account details to use these sources.
