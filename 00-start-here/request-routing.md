# Request Routing

Reviewed: 2026-09-06. Use one primary route; open another only when the decision requires it.

| Request | First local route | Targeted escalation |
|---|---|---|
| Complete build, optimize a loadout | [Build intake](../builds/build-request-protocol.md) | Relevant class candidates, Compendium, current artifact and damage evidence |
| One ability, perk, exotic, or mod | [Mechanics source map](../data/compendium-index.md) | Exact live tab or Clarity |
| Boss damage, swap, speedrun | [Damage and survival math](../builds/damage-and-survival.md) | Boss Damage: current row, conditions, and encounter |
| Keep/shard, god roll, weapon chase | [Weapons](../gear/weapons.md) | Personal alternatives, Endgame Analysis, Foundry/manifest |
| Armor optimization or set bonus | [Armor](../gear/armor.md) | Armor Perks, Game Mechanics; owned optimizer |
| Artifact selection | [Artifacts](../builds/artifacts.md) | Current Artifact Perks, Artifact Mods ratings, known issues |
| Exotic acquisition, catalyst, crafting | [Exotics](../gear/exotics.md), [crafting/catalysts](../gear/catalysts-and-crafting.md) | Exact source, eligibility, and completion condition |
| Raid/dungeon/Pantheon mechanics | [Guide protocol](../activities/guide-protocol.md) and exact activity index | Current guide/map plus encounter-specific damage |
| Ops, campaigns, exotic missions, Champions, Banes | [PvE](../activities/pve.md) | Exact modifier/objective; Compendium or current guide |
| Trials, Comp, Iron Banner, Crucible | [PvP](../activities/pvp.md) | Live playlist rules, weapon model, current map |
| Gambit | [Gambit](../activities/gambit.md) | Current rules and separate combatant/Guardian behavior |
| SRL | [Pantheon and SRL](../activities/pantheon-and-srl.md) | Exact track, objective, and reward |
| Quest step | [Quests](../progression/quests.md) | Exact objective wording and source |
| New/returning, campaign order, Power | [New and returning](../progression/new-and-returning.md) | Official access and current Power rules |
| Unlocks, titles, seals, Guardian Rank, collectibles | [Unlocks and collections](../progression/unlocks-and-collectibles.md) | Personal checklist, Braytech, exact triumph text |
| What to farm | [Farming](../progression/farming.md) | Exact loot table, repeatability, active reset |
| Materials, vendor spend, focusing | [Currencies](../progression/currencies.md) | Current cost and owned budget |
| Monument/rewards passes/events | [Seasonal and Monument](../progression/seasonal-and-monument.md) | Official availability and present vendor |
| Vault, DIM, armor CSV, personal data | [Data index](../data/local-resource-index.md) | Latest relevant personal source |
| Lore, story, fashion, accessibility, error codes | [Lore/fashion/support](lore-fashion-and-support.md) | Ishtar, Collections, or official Bungie support |
| Update this helper | [Maintenance](../maintenance/README.md) | Scoped source audit and validation |

For unsupported Destiny 2 topics, search the registry and the exact topic, then give a sourced answer. The index is a routing map, not a restriction to listed activities. Mention a missing note only if it matters to the answer.
