# Personal Data and Reference Data

Reviewed: 2026-09-06. See [local resource index](local-resource-index.md) for what actually exists.

## Personal imports

Raw user-provided files belong in [exports](exports/README.md). When asked to import, inspect the file read-only and summarize useful facts into Markdown under this folder.

Record source filename, export/observation date, import date, account/character coverage, filters, and completeness. Preserve instance identities for similar weapon/armor rolls when supplied. Keep original files and prior snapshots unless deletion is requested.

Use the newest relevant data per fact, not merely the newest file overall. A new weapon-only export does not supersede an armor export; a filtered export does not prove omitted items are unowned. Explicit user corrections can update a fact without rewriting an entire historical snapshot.

Separate owned, unlocked, obtained, completed, equipped, crafted, and recommended. A saved build is not an inventory export.

## Public references

Use [Compendium map](compendium-index.md) for local exact values and [live sheets](live-google-sheets.md) for narrow current reads. The catalyst images and eight June workbooks are public reference material. They contain no confirmed personal gear or progress.

Keep public sheets live. Do not silently create copies, refresh archives weekly, or use public rows as account ownership. See [snapshot policy](snapshots/README.md).

## Useful summaries after data exists

| Summary | Capture |
|---|---|
| Weapons | Exact versions/rolls, roles, duplicates, keep/shard rationale, replacement |
| Armor | Class, slot, instance, stats, tier, archetype, set, energy, upgrade state |
| Exotics/class items | Owned items and exact Spirit pairs |
| Catalysts/patterns | Obtained/completed/applied status and next action |
| Quests/triumphs | Exact objective, character/account scope, current step, blocker |
| Currencies | Amount, date, target spend, reserve |
| Activity history | Actual clears, roles, difficulties, observed issues |

Do not create empty "owned gear" summaries that look authoritative before data is available.
