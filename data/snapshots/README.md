# Public Reference Snapshots

Policy reviewed: 2026-09-06.

Existing dated public workbooks are historical references, not personal inventory and not automatically current measurements.

- Preserve existing files unless deletion is requested.
- Do not delete or redownload weekly.
- Do not create a snapshot just because a live reader is blocked.
- Prefer exact live tabs/ranges for current analysis and the external Compendium for the first mechanics lookup.
- When a snapshot is explicitly requested, record source, date, scope, purpose, and limitations.
- If a historical snapshot is the only usable evidence, identify its date and mark the conclusion provisional.

The existing archive is [2026-06-16](public-sheets/2026-06-16/README.md). The external [Compendium](../compendium-index.md) is a separate user-provided reference and should not be copied here during routine work.
