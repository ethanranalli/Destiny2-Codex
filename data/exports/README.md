# Exports Folder

Use this folder for personal files you add later, such as Excel, CSV, DIM, vault, weapon, armor, catalyst, triumph, or checklist exports.

Public Google Sheets should stay as live links in `data/live-google-sheets.md` unless a one-time snapshot is explicitly requested.

When a new personal export is added, summarize the important parts into Markdown under `data/` and record it in `data/README.md`.
