# Artifacts

Reviewed: 2026-09-06. For current picks search the local Compendium's **ARTIFACT PERKS (CURRENT)** section, then verify changes/unknowns in the live **Artifact Perks** tab. Do not use its OLD tabs.

The checked rules offer seven reworked artifacts and three selection tiers. Artifact selections save with loadouts; Competitive and Trials disable them. Intrinsic weapon Champion effects replaced the dedicated seasonal anti-Champion selections. See [Bungie's artifact preview](https://www.bungie.net/7/en/News/article/dev_insights_weapons_artifacts_focusing_preview).

Search these exact families; verify spelling against the actual item:

- Hunter's Journal
- Queensfoil Censer

These are names for lookup, not seven simultaneous equipment choices. Older seasonal versions with the same name can have different effects.

## Pick workflow

1. Determine mode, weapon roles/elements, subclass triggers, encounter, and survival needs.
2. Compare relevant artifacts against the entire loadout. A passive survival or ammo engine may beat a conditional damage perk.
3. Read each chosen perk's current definition: tier, activation, duration, target restrictions, cooldown, PvE/PvP differences, stacking, and known issues.
4. Verify current selectable count in each tier and overall allocation from the live item/UI. Do not reuse an old 12-selection layout or guess caps.
5. List every selected perk grouped by tier and mark mandatory versus selected flex. Give named alternate picks, not a menu of simultaneously equipped options.
6. Explain what changes when weapons, Super element, teammate buffs, modifiers, or armor change.
7. Recheck weapon Champion coverage and the armor-charge/ammo loop with these selections active.

If an exact current pick/limit cannot be read, provide a provisional artifact plan and name the gap. Do not present a fully validated build with missing artifact data.

## Changes and issue checks

The [9.7.0 notes](https://www.bungie.net/7/en/News/Article/destiny_update_9_7_0) changed several familiar perks, including Torch, Solo Operative, Flashover, Limit Break, and Particle Reconstruction. Match the current entry; old videos can misstate their purpose or power.

The [known-issues page](https://help.bungie.net/hc/en-us/articles/39007140765204-Destiny-2-Known-Issues-and-Vital-Information), checked September 6 with a July 7 Monument section date, lists issues affecting Argent Blade charge generation and several elemental perks. Check the exact selected perk and later fixes; do not declare all listed bugs still active without reconciliation.

The [9.7.0.2 patch](https://www.bungie.net/7/en/News/Article/destiny_update_9_7_0_2) addressed duplicate artifact selections; existing saved selections deserve a check. [9.7.0.3](https://www.bungie.net/7/en/News/Article/destiny_2_update_9_7_0_3) includes a Pack Tactics performance fix.
