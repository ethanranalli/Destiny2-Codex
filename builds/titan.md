# Titan Candidate Map

Reviewed: 2026-09-06. Lower priority unless requested, or useful for a team composition. This map is not a current performance ranking.

| Subclass / role | Candidate anchors to investigate | Required checks |
|---|---|---|
| Solar / sustain or burst | Loreley Splendor Helm, Synthoceps, Pyrogale Gauntlets, Hallowfire Heart | Exact ability/Super support, healing, safe range |
| Void / defense and support | Helm of Saint-14, Ursa Furiosa, Precious Scars | Super/barricade/weapon trigger, team benefit, current defense rules |
| Arc / burst or grenade | Cuirass of the Falling Star, Heart of Inmost Light | Correct Super or ability loop, target access and cast time |
| Stasis / crystals or control | Hoarfrost-Z, Icefall Mantle | Current ability/replacement and Frost Armor interactions |
| Strand / suspend or melee | Abeyant Leap, Synthoceps, Wormgod Caress | Safe engagement, stacks, woven mail/control, additive damage rules |
| Prismatic / combined engines | Stoicism with an exact legal pair, or compatible standard exotic | Perk columns, Prismatic abilities, Super and Transcendence |
| PvP / objectives | Compare barricade, movement, handling, and survivability choices | Playlist, first duel, map/range, actual Guardian effects |

Stoicism is a Prismatic perk source; remove it from pure-element configurations. Include Titan in a Hunter/Warlock answer only if the user's team plan makes it material.
