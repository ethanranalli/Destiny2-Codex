# Builds

Reviewed: 2026-09-06.

For any complete build:
1. Read [intake](build-request-protocol.md).
2. Use the relevant [Hunter](hunter.md), [Warlock](warlock.md), or [Titan](titan.md) candidate map.
3. Apply the [framework](buildcrafting-framework.md) and current mechanic evidence.
4. Validate with [build validation](build-validation.md).
5. Present the [complete build card](build-output-template.md).
6. If saving is requested, add the metadata from [saved-build template](build-template.md).

Additional routes: [artifacts](artifacts.md), [damage and survival](damage-and-survival.md), [armor](../gear/armor.md), [live sheets](../data/live-google-sheets.md).

The class files are search starting points, not fully specified or ranked meta builds. A named exotic alone is not a finished build. The maintenance audit did not prove any build in game.

A small follow-up changes only the relevant part of the card unless it breaks the rest of the setup. If a weapon swap changes Champion coverage, artifact triggers, mods, or damage timing, update those dependent parts too.
