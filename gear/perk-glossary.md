# Perk Evaluation and Terminology

Reviewed: 2026-09-06. This is a reasoning glossary, not a replacement for exact current Compendium entries.

| Role | What to check |
|---|---|
| Damage | Target category, trigger, duration, stacking category, PvE/PvP scaling |
| Reload / rotation | Activation delay, magazine refill versus reserves, stow behavior, swap timing |
| Ammo | Reserves, refunds versus generation, eligible ammo type, cooldown |
| Add clear | Radius, kill/hit trigger, chaining, falloff, ability/weapon attribution |
| Survival | Healing, overshield, resistance, actual uptime, need for a kill |
| Ability energy | Flat return, base recharge, instant refund, charge behavior, scalar |
| Subclass synergy | Exact verb, selected ability/Super element, pickup generation/consumption |
| Control | Suppress, slow, freeze, suspend, blind/disorient; bosses and Champions can differ |
| Team utility | Ally radius, ownership, stack/overwrite behavior, practical coordination |
| PvP consistency | Range, stability, handling, accuracy, recoil, flinch, airborne behavior |

Weaken/vulnerability and crowd control are different categories. Scorch, suppression, and ignition are not interchangeable with a global damage debuff. Use [stacking rules](../builds/damage-and-survival.md).

For each recommendation answer: what triggers it, how often it works here, what it replaces, and what fails when the trigger disappears. Enhanced variants and origin traits deserve their own current checks.

Use [weapon verdicts](weapons.md) for labels. Do not duplicate a static list of all perk numbers here; search [the Compendium](../data/compendium-index.md).
